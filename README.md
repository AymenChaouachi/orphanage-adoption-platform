# Orphanage & Adoption Platform

## Concept

A web application designed to safely match children with verified families.

The system ensures:
- Adopters are verified
- Dangerous individuals are blocked
- Compatibility is calculated logically
- Every child gets a fair chance

## Features

- Family profile creation
- Child profile creation
- Automatic adopter verification
- Dangerous name blocking system
- Compatibility scoring algorithm
- Transparent approval explanation

## Tech Stack

- Node.js
- Express
- Vanilla HTML/CSS

## How to Run

1. Install dependencies:
   npm install

2. Start server:
   node server.js

3. Open:
   http://localhost:3000
